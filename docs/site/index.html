LOAD IT IN CIW

One file.
Native shortcuts.

  1. 01Keep the nlayout/ directory intact, including its display resources and icons.
  2. 02Load numeric_assist.il from CIW or add the same line to your local .cdsinit.
  3. 03Use the ruler toolbar button to toggle the assist. Run vbnUninstall() to restore previous bindings.

Prefer a packaged download? Get the latest release ↗. The archive and its SHA1 checksum ship together.

A SMALL HABIT. A PRECISE EDIT.

Stay in the native command.
Lose the grid math.

NLayout rides along with Rectangle, Path, Wire, Measurement, Stretch, Move, and Copy. Pick a value, type it digit by digit, confirm, and keep drawing.

Pick → Width → Measurement → Copy. The interactive version also includes Stretch, Move, Contour, and Steiner cleanup.

LOAD IT IN CIW

One file.
Native shortcuts.

The deployable runtime lives in src/. Point Virtuoso at the file and the toolbar and key bindings install themselves.

  1. 01Keep the src/ directory intact, including its display resources and icons.
  2. 02Load numeric_assist.il from CIW or add the same line to your local .cdsinit.
  3. 03Use the ruler toolbar button to toggle the assist. Run vbnUninstall() to restore previous bindings.
